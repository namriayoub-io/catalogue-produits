 
# TP JavaScript – Gestion des produits

## Description

Ce projet a pour objectif de pratiquer les bases de JavaScript à travers un exercice de gestion d'un catalogue de produits.

## Objectifs

- Manipuler des tableaux et des objets.
- Utiliser les méthodes `map()`, `filter()` et `reduce()`.
- Calculer le nombre de produits disponibles.
- Calculer la valeur totale du stock.
- Trouver le produit disponible le moins cher.
- Utiliser la déstructuration des objets.
- Vérifier la validité des données avec `Number.isFinite()`.

## Technologies utilisées

- JavaScript
- Git
- GitHub

## Fonctionnalités

- Affichage des noms et des prix des produits.
- Comptage des produits disponibles.
- Calcul de la valeur totale du stock.
- Recherche du produit disponible le moins cher.
- Validation des données des produits.
- Affichage d'un résumé du catalogue.

## Exemple de données

| Produit | Prix | Stock |
|---|---:|---:|
| Clavier | 120 MAD | 5 |
| Souris | 80 MAD | 8 |
| Écran | 900 MAD | 0 |
| Casque | 240 MAD | 3 |

## Résultats attendus

- Nombre de produits disponibles : **3**
- Valeur totale du stock : **1 960 MAD**
- Produit disponible le moins cher : **Souris**
- Prix du produit le moins cher : **80 MAD**
